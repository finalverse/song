# Song brand assets

This directory is the source of truth for the Finalverse Song visual identity.

- `brand-guidelines.md` defines naming, voice, color, and compatibility usage.
- `tokens.json` contains portable design tokens.
- `logo/song-mark.svg` is the transparent standalone Song Note mark: one musical note whose curved stem forms an “S”.
- `logo/song-lockup.svg` is the horizontal product lockup.
- `logo/song-app-icon.svg` is the cross-platform app icon master.

Generated platform assets should be derived from these SVG masters. Do not edit individual PNG sizes as independent artwork.
