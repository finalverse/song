# Finalverse Song brand guidelines

## Brand idea: the Song Note

Song turns musical intent into structured music that can keep evolving. The mark is a single eighth note drawn as a flowing “S”: its notehead represents a musical idea, its curved stem represents an editable creative path, and its flag points toward performance. It should read as both a note and the initial for Song without relying on a literal letterform.

## Naming

| Context | Name |
|---|---|
| Product | Song |
| Desktop application | Finalverse Song Studio |
| Compact application label | Song Studio |
| Company / legal owner | Finalverse Inc. |
| Product website | `song.finalverse.com` |
| Company product route | `finalverse.com/song` |
| Repository | `github.com/finalverse/song` |

Use **Song** in conversational product copy. Use **Finalverse Song Studio** in package names, About, installers, first launch, and legal/product metadata. Do not use “Finalverse Studio” as a short name because it can be confused with other Finalverse products.

## Positioning line

Primary: **From an idea to a living score.**

Descriptor: **AI-native music creation**

Long-form positioning: **Compose, arrange, play, and publish music with human craft and AI intelligence in one editable workspace.**

## Voice

Song is clear, musical, and collaborative.

- Speak like a capable creative partner, not an autonomous replacement for the musician.
- Prefer concrete musical verbs: compose, arrange, voice, align, listen, compare, refine.
- Explain what an AI suggestion changes and why.
- Avoid inflated claims about taste, originality, or authorship.
- Call an AI edit a “suggestion” or “change” until the user applies it.

## Color system

| Token | Value | Use |
|---|---:|---|
| Midnight | `#090B14` | Primary dark canvas and app icon |
| Deep Violet | `#17122B` | Elevated dark surfaces |
| Score Paper | `#F7F7F2` | Light canvas and high-contrast text |
| Resonance | `#7C5CFF` | Primary brand and AI action |
| Signal | `#2DE2C5` | Playback, success, active intelligence |
| Chorus | `#FF5C8A` | Expressive accent and collaboration |
| Sky | `#61B7FF` | Links and secondary information |
| Ink | `#171923` | Text on light surfaces |

The primary gradient runs from Resonance through Chorus to Signal. Use it on the mark and rare high-salience moments, not as a general background fill.

## Logo usage

- Keep clear space around the mark equal to half the height of its notehead.
- Use the full-color mark on Midnight, Deep Violet, Score Paper, black, or white.
- At small sizes, use the mark without the wordmark.
- Preserve the single-note silhouette; do not add a second note, staff, robot head, sparkle, or separate “AI” badge to the mark.
- Do not substitute a font glyph or emoji for the drawn Song Note.
- Do not recolor individual parts of the mark outside the approved gradient or one-color variants.

## Typography

The application continues to use native/system UI typography for performance, localization, and accessibility. Marketing and future web surfaces should prefer a modern variable sans with broad language coverage. Musical content continues to use the existing engraving fonts.

## Compatibility language

The fork preserves MuseScore-compatible formats and APIs. Use “MuseScore-compatible score” when explaining `.mscz` or `.mscx` files to users. Keep the exact MuseScore name for:

- historical attribution and copyright;
- the `MuseScore Basic` sound profile;
- native file formats, MIME types, and UTIs;
- legacy plugin/QML APIs;
- migration messages describing a specific MuseScore version.

Do not perform a global replacement of the MuseScore name.

## Attribution

The About dialog and repository documentation must state that Finalverse Song Studio is based on MuseScore Studio and preserve the GPL v3 license and upstream copyright notices. New Finalverse copyright does not replace upstream attribution.
